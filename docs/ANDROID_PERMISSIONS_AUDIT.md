# Разрешения и локальные данные

Приложение использует локальный игровой профиль: игровое имя, выбранного питомца, баланс и операции с игровыми монетами, цель, накопления, покупки, задания и прогресс. Регистрация и реальные платёжные данные для игрового цикла не используются. Профиль хранится на устройстве в Unity PlayerPrefs; раздел взрослого позволяет удалить его с подтверждением.

Разрешения из манифеста подписанного `Finik-release.apk` получены командой `aapt dump permissions`:

| Разрешение | Назначение |
| --- | --- |
| `android.permission.INTERNET` | Техническое разрешение Android-сборки; основной игровой цикл реализован локально |
| `com.finik.game.DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION` | Техническое разрешение компонента Android, не открывающее доступ к данным пользователя |

Камера, микрофон, геолокация, контакты и Bluetooth в манифесте APK не запрошены. SHA-256 проверенного файла указан в [отчёте Android](ANDROID_QA_REPORT.md).
