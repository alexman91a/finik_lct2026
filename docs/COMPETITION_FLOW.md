# Сквозной сценарий проверки

Последовательность соответствует [Приложению А ТЗ](customer/6.%20Департамент%20финансов%20города%20Москвы.pdf). Для показа дохода по заданию используется задание с наградой: первое ознакомительное задание опирается на стартовые монеты и отдельно не оплачивается.

| Шаг | Действие и наблюдаемый результат |
| --- | --- |
| 1 | Установить APK и запустить приложение. Пройти короткое знакомство с решениями: потратить на нужное, потратить на желаемое, отложить. |
| 2 | Создать локальный профиль без настоящего имени, телефона и e-mail. |
| 3 | Выбрать внешний вид и игровое имя питомца. |
| 4 | Найти стартовый бюджет, текущую цель и доступные задания на главном экране. |
| 5 | Распределить монеты между «Нужно / Хочу / Коплю», подтвердить план. Сумма не превышает доступный бюджет. |
| 6 | Выполнить задание с игровой наградой и прочитать объяснение результата. Проверить источник и сумму начисления. |
| 7 | Совершить по одной нужной и желаемой покупке. Повторить попытку при нехватке монет: покупка не проходит, баланс не становится отрицательным, интерфейс объясняет следующий шаг. |
| 8 | Выбрать финансовую цель, пополнить копилку и проверить «стоимость / накоплено / осталось». |
| 9 | Сравнить план и факт, проверить изменение баланса, накоплений и состояния питомца. |
| 10 | Перейти к следующему игровому периоду и показать изменение прогресса или стадии после серии решений. Демонстрационный режим позволяет пройти пять периодов без календарного ожидания. |
| 11 | Полностью закрыть приложение и открыть снова: профиль, баланс, цель, покупки и прогресс сохранены, доход не начислен повторно. |
| 12 | Открыть отделённый барьером раздел взрослого и подтвердить сброс или удаление демонстрационного профиля. |

По ответам заказчика, все пять периодов за одно выступление показывать не требуется. Результаты проверки сборки приведены в [отчёте Android](ANDROID_QA_REPORT.md).
